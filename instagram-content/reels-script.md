# ayarlıyo Reels — Anlatıcı Script

## ElevenLabs Ayarları
- **Ses:** "Fatih" veya "Onur" (Türkçe erkek), ya da "Zeynep" (kadın)
- **Stability:** 0.55 | **Clarity:** 0.80
- **Hız:** 1.0x (normal)

## Script (toplam ~17 saniye)

```
Salonunu ayarlıyo'ya bağla.

Müşteri hizmetini seçiyor.

Tarihini belirliyor.

Bilgilerini giriyor.

Randevu onaylandı.

Ve WhatsApp'a otomatik bildirim gidiyor.

ayarlıyo — randevu artık senin işin değil.
```
